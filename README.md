# Сова — ИИ-администратор для салонов и студий

Демо-лендинг сервиса, который отвечает клиентам в чате в любое время и записывает их на услугу. Главное на странице — рабочий чат: он разбирает свободный текст («хочу на маникюр в субботу после обеда»), уточняет недостающее, проверяет расписание и создаёт запись. Рядом видно, что именно поняла Сова. Чистые HTML, CSS и JavaScript, без зависимостей и сборки.

## Что внутри

- чат с разбором услуги, дня, времени и имени из одной фразы; отмена записи, вопросы о ценах, адресе и графике, передача жалоб администратору
- панели «Что поняла Сова», расписание с занятыми окнами и журнал записей
- калькулятор потерянных записей с расчётом окупаемости (и честным «не окупится»)
- блоки: как работает, что умеет, пакеты, вопросы
- адаптив и `prefers-reduced-motion`, данные пользователя выводятся через `textContent`

Демо работает по заданным правилам в браузере и ничего не отправляет. В реальном проекте подключаются языковая модель, календарь и база знаний клиента.

## Запуск

Открыть `index.html` или `python3 -m http.server`.
